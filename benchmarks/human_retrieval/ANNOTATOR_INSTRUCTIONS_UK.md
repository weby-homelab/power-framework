# Інструкція оцінювачу M2-v2

Це коротка оцінка українською мовою. Не потрібно знати код, GitHub або назви
режимів пошуку. Ви отримуєте запитання та чотири короткі документи.

## Для кожного документа

Оберіть три значення:

- `relevance`: `2` — прямо відповідає; `1` — пов'язаний, але не відповідає
  сам; `0` — не допомагає відповісти.
- `acceptable_citation`: `true` лише якщо документ можна прямо процитувати як
  підтвердження відповіді. Для `relevance` `0` або `1` ставте `false`.
- `temporal_status`: `current`, `historical` або `not_applicable`. Орієнтуйтеся
  лише на явний статус у тексті документа.

Не використовуйте `-1`, додаткові категорії чи вільний текст. Не шукайте
відповіді в інтернеті та не обговорюйте відповіді з іншим оцінювачем.

## Приклад формату відповіді

Один JSON-рядок на одну пару:

```json
{"participant_id":"ANN-A01","query_id":"dev-q-001","document_id":"doc-001","relevance":2,"acceptable_citation":true,"temporal_status":"current"}
```

`participant_id` надає координатор. Не публікуйте raw judgments у GitHub.

Спочатку виконується коротка calibration з тією самою шкалою. Production
дозволяється лише після перевірки agreement receipt координатором.
