# POWER 3.7.15 — Linux core, CLI and MCP

This maintenance release includes the [3.7.14 doctor fixes](release-3.7.14.md)
and the native dependency refresh. The Linux artifacts are the wheel, source
distribution, hash-pinned native requirements, package SBOM, manifest, checksums,
acceptance evidence and release receipt. No Web container is published or
deployed by this release. The Web source stays in the repository.

See [Getting Started](getting-started.md) for the Python 3.13/3.14 installation
and the `power` and `power-mcp` launchers. Verify `SHA256SUMS` with GitHub's
build-provenance attestation before checking the downloaded assets against it.
