# ADR 0005: Read-Only Federation and A2A 1.0 Interoperability Adapter

**Status:** Accepted

**Date:** 2026-08-13

## Decision

POWER 3.7 defines clear and bounded protocols for multi-vault federation and agent-to-agent (A2A) interoperability:

1. **Read-Only Federation:** Federation is strictly a read-only registry and query fan-out across independent POWER instances. It preserves origin provenance, marks partial failures explicitly, and never synchronizes or mutates remote vaults automatically.
2. **A2A 1.0 Interoperability Adapter:** The A2A adapter is an optional, least-privilege projection over POWER `ApplicationService`. It advertises bounded skills (`power.search`, `power.source.read`, `power.task.request`, `power.proposal.request`). It does not expose raw shell execution or autonomous mutation.
3. **No Authority Escalation:** Remote agent requests or federated search hits never elevate local authority. Any proposal originating from an external source requires explicit local human approval before application.
